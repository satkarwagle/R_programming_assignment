# MacTahoe Quick Settings Blur

Glass-like blur for GNOME Shell 49 Quick Settings and the Calendar/Notifications
menu, tuned for the macOS Tahoe theme.

## Install
1. Copy the folder `mactahoe-quicksettings-blur@local` to:
   `~/.local/share/gnome-shell/extensions/`
2. Restart GNOME Shell, then enable:
   `gnome-extensions enable mactahoe-quicksettings-blur@local`

## Notes
- This extension focuses on Quick Settings and the Calendar/Notifications menu.
- The blur intensity is controlled in `extension.js` (`BLUR_SIGMA`).
- Glass styling can be adjusted in `stylesheet.css`.
